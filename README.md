# Project-s
A simple, modern-looking calculator application built using C# and Windows Presentation Foundation (WPF). The application provides basic arithmetic operations through an interactive graphical user interface, featuring a custom Polish Cow background.

  Features:
- Basic Arithmetic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Additional Calculator Functions
- Clear (C) – Resets the calculator.
- Delete (⌫) – Removes the last entered digit.
- Percentage (%) – Converts a number into a percentage.
- Plus/Minus (±) – Changes the sign of a number.
- Decimal Point (.) – Allows decimal number input.
- User Interface
- Custom button styles and colors.
- Rounded buttons with hover effects.
- Large, easy-to-read result display.
- Custom Polish Cow GIF background.
- Fixed window size and centered startup position.
- Calculation Handling
- Supports chained calculations.
- Limits number input to 12 characters.
- Rounds long decimal results to 8 decimal places.
- Uses scientific notation for very large or very small results.
- Displays an error message when attempting to divide by zero.

  Technologies Used
C# – Handles calculator logic and button interactions.
WPF (Windows Presentation Foundation) – Creates the graphical user interface.
XAML – Defines the layout, buttons, styles, and visual elements.
.NET – Provides the application framework.

  Installation
- Clone or download this repository.
- Open the project folder.
- Open the .sln solution file in Visual Studio.
- Make sure the polish-cow-cow.gif file is included in the project and configured as a WPF resource.
- Build the project using Build → Build Solution.
- Run the application by pressing F5 or clicking Start in Visual Studio.

  Implementation Details
The application uses event-driven programming. Each calculator button is connected to a corresponding C# event handler defined in MainWindow.xaml.cs.

  The main variables used to manage calculations are:
currentInput – Stores the number currently displayed.
currentOperation – Stores the selected arithmetic operator.
firstNumber – Stores the first operand.
isNewCalculation – Determines whether a new calculation is starting.
isOperationJustPressed – Tracks whether an arithmetic operator was just selected.
The CalculateResult() method performs the selected arithmetic operation using a switch statement.
